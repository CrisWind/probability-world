# 概率世界｜承保咖啡馆港口探索

1687 年灰湾港的像素风概率教学游戏。你将从承保咖啡馆出发，在港口街道、造船厂与商会之间活动：通过承保决策、抽样质检、船队风险盘和风闻判断，亲手"撞见"概率与统计的核心概念——不是在课堂上听讲解，而是在经营里踩坑、复盘、调整。

纯浏览器运行，无需安装：Phaser 3 + 原生 JS/DOM + localStorage 存档。

## 玩法功能

- **港口街道探索**：像素场景自由走动，白天 / 黄昏 / 夜晚随时间流转，NPC 各有日程。
- **承保咖啡馆（主店玩法）**：为往来商船承保出价，体验信息不对称下的逆向选择与赢家诅咒；咖啡馆也是风闻流转的中心。
- **风闻局**：在众说纷纭的传言中做判断，亲历羊群效应与信息瀑布如何左右价格。
- **造船厂质检房**：对一批新船做抽样检验并决定放行或返工——抽样误差、批量判定、检验成本与风险的取舍都藏在数字里。
- **商会船队风险盘**：制定船队与航线计划，跑完整整 5 回合的风暴季 campaign；遭遇与共同风险会在多艘船之间联动，迫使你依据观察调整策略，而不是靠运气。
- **共同风险观察与策略调整**：把各玩法中观察到的风险规律沉淀为可复用的判断依据，在终局总结中回顾这一季学到了什么。
- **港口笔记**：自动记录你真实经历过的承保、质检与船队事件，随时回看自己的决策轨迹。
- **任务 / 成就 / 称号 / 背包**：从"一张没有贴出的船讯"到"风暴季的账本"，任务簿指引一条完整教学主线；成就与称号奖励探索深度。
- **时间与行动点**：港口的每一天都要计划着花，存档可随时保存/重置。

## 运行方式

- 直接双击 `index.html` 即可游玩（所有素材与字体均已本地化，支持 `file://`）。
- 或起一个本地静态服务器，例如：`python -m http.server` 后访问 `http://localhost:8000`。

## 技术架构

- 内部画布 480×270，像素风放大渲染；HUD 为 DOM 叠加层。
- 单文件主线 `index.html`（场景 / 精灵 / NPC / 内联 CSS）+ 模块化 JS：
  - `game-store.js` — 存档单一事实来源（localStorage，键 `probability-world-save-v1`）
  - `quest-*.js` / `achievement-*.js` / `task-ui.js` — 任务、成就与任务簿 UI
  - `shipyard-runtime.js` / `shipyard-ui.js` — 造船厂质检与抽样判定
  - `fleet-*.js` / `fleet-ui.js` — 商会船队风险盘 campaign 模型与 UI
  - `sampling-learning.js` / `fleet-learning.js` / `learning-adapter.js` — 学习证据记录
  - `harbor-notes.js` — 港口笔记
- 存续进度全部保存在浏览器 localStorage；点界面右下角 ↻ 可重置测试存档。

## 仓库结构

```

*.js                各玩法模块
scripts/            开发期补丁与回归测试脚本（node 运行）

```
